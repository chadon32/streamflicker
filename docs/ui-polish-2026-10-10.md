# UI polish — October 10, 2026

This follows the October 1 review (`ui-review-fixes-2026-10-01.md`), which fixed contrast, text size, honesty of the data and performance. This pass is about consistency: the same thing should look and behave the same everywhere. Nothing about search, filters, the planner's rules, data or storage changed.

## Design direction

Kept: the dark near-black page, the rose brand color, Outfit for display and Inter for text, the logo. No new dependency or font.

**Palette** (Tailwind 4 names; the build emits the exact oklch values)

| Role | Value |
| --- | --- |
| Page | `#070709` |
| Raised surface (cards, controls) | `zinc-900`, borders `zinc-700` (controls) and `white/8%` (dividers) |
| Dialog surface | `#0c0c10` |
| Text | `zinc-50`/`zinc-100`, secondary `ink-2` `#a1a1aa` (7.9:1), captions `ink-3` `#8a8a94` (5.9:1) |
| Accent, the only one | `rose-600` primary (`oklch(58.6% .253 17.6)`), hover `rose-700`, selected `#4c1024` with a `rose-400` border, links and step labels `rose-300` |
| Saved or done | emerald (`btn-saved`, saved card bookmark, success messages) |
| Be careful | amber (content notes, warnings) |

**Type scale**: captions, meta, legal and labels 12 px; UI text (buttons, chips, links, subtitles) 14 px; body copy 16 px; dialog and card titles 16 to 18 px Outfit bold; row headings 20/24 px Outfit black; section headings 30/36 px; page titles 30/36/48 px (home) and 48/60/72 px (About, guide), Outfit black.

**Spacing**: Tailwind's 4 px grid. Controls 44 px tall (48 px for a page's main call to action); 8 px between chips; 24 px from the discovery row to the hero; 32 px between rows; 48 px before the explainer. Page content, header and footer share one left edge (`max-w-7xl`, 16/24/32 px gutters).

**Radius**: 12 px for every control (buttons, chips, inputs, search); 16 px cards; 24 px dialogs and the hero; round only for icon-only buttons and read-only tags.

**Components** (`src/index.css`, `@layer components`, so utilities still compose with them)

| Class | Use |
| --- | --- |
| `btn` + `btn-primary` / `btn-secondary`, `btn-lg`, `btn-saved` | Every button. One primary per view |
| `icon-btn` | Round icon-only controls (row and hero arrows) |
| `chip`, `chip-count`, `chip-selected` | Every toggle: shortcuts, filters, planner options, streaming services. Selected state comes from `aria-pressed` |
| `tag` | Read-only labels (themes, providers) |
| `eyebrow`, `eyebrow-brand` | Section labels; rose only where it introduces a step |
| `notice`, `notice-warn` | Supporting information; amber only for warnings |

Checks: `npm test`, `npx tsc -b`, `npm run lint`, `npm run build` and `npm run test:seo` pass. A scripted audit of 10 screens (pages, the planner, filters, the movie dialog, settings, search with and without results) at 375 and 1440 px found no contrast failures, unnamed controls, duplicate ids or heading skips, and no horizontal overflow at 375, 768 or 1440 px. Tabbing through the home page reached 79 controls, each with a visible focus ring.

`scripts/test-ui-guards.mjs` now also fails on: accent colors other than rose, emerald and amber; hand-styled rose buttons (`bg-rose-600` outside `.btn-primary`); white buttons (`bg-zinc-100`); a page that builds its own footer instead of `SiteFooter`; and missing shared classes.

## Not changed (your call)

- **The hero always shows Blade Runner 2049**, which is also the first Top pick, and John Wick appears in both rows. With 17 reviewed titles that repetition is built in; flagging two or more reviewed titles as featured would rotate the hero.
- **"All years 1,799" versus "Browse all 1,798"**: one title the catalog can prove is unreleased is hidden from browsing but still counted in the filter facets. Aligning them is a logic change.
- **The provider disclaimer** above every result grid is long. It came from the honesty work on October 1; it could shrink to one line with a "why" link.
- **The planner's Save and Copy bar** stays pinned while the picks scroll under it. It now matches the dialog and casts a shadow, but a pick's buttons can still sit behind it until you scroll.
- **The iPhone app** ships the web bundle: run `npm run ios:sync` and rebuild to pick this up, and the App Store screenshots will need retaking.
